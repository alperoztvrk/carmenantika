# Carmen Antika — Brand Spec

## Design read

- **Artifact:** public-facing antique marketplace / e-commerce storefront
- **Visual language:** editorial object journal, warm archive, quiet luxury
- **Audience:** design-conscious shoppers looking for one-of-a-kind vintage furniture and objects
- **Mode:** redesign / overhaul from a clean scaffold
- **Motion intensity:** 4/10 — restrained reveals, hover zooms, responsive drawers
- **Information density:** 5/10 — generous whitespace, catalog-forward product grid
- **Asset dependence:** 8/10 — product and interior photography lead the experience

## Tokens

- Parchment: `#F3EBDD`
- Paper: `#FBF8F1`
- Ink: `#2F251F`
- Terracotta: `#A95238`
- Moss: `#5D684F`
- Aged brass: `#B38A4B`
- Border: `#D9C8AD`

## Typography

- Display: Cormorant Garamond
- UI/body: DM Sans
- Display style: large editorial serif, tight leading, restrained italic emphasis

## Image assets

Product and interior photography currently use remote Unsplash URLs as temporary editorial placeholders. Replace these with Carmen Antika-owned product photography when available. The typographic `Carmen Antika` wordmark is intentionally used until an official logo asset is provided.

## Interaction language

- Hover image zoom: 600–900ms custom ease-out
- Buttons: 180ms lift/press feedback
- Drawer: 350ms right-to-left ease-out
- Marquee: low-frequency ambient motion
- All non-essential motion is disabled under `prefers-reduced-motion`
